# ComplexNN-segment
复值神经网络用于复值遥感数据的语义分割


## 主要文件介绍
- Model.py : 包含了Complex Unet网络的模块
- train.py : 模型训练的入口, 里面配置了模型的参数, 以及本次实验的记录数据
- mlruns/  : 训练日志的保存位置, 在终端使用`mlflow ui`来运行, 查看模型效果

## 训练模型的指标:
1. val_acc: 测试集上的分类准确度
2. val_mIoU: 这个也是分类准确度的一种指标, 一般认为, mIoU>70%, 模型初步训练好

## 目前模型存在的问题
1. 严重的过拟合现象, 在训练集上可以实现99%的准确度, 测试集上, 仅有20%

怀疑是遥感数据的问题。原来使用polSF的数据，里面噪声很大，而且对不同语义分割的精度不高，都是一大片一大片的划分。
